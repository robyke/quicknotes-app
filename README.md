# QuickNotes

QuickNotes is a simple note-taking web app built with HTML, CSS, and JavaScript. It allows users to create notes, organise them by category, search through saved notes, delete notes, and keep their notes after refreshing the browser using localStorage.

## Features

- Add new notes
- Choose a category: Personal, Work, or Study
- Delete individual notes
- Search notes by text
- Validate empty notes and notes over 200 characters
- Display the correct number of notes
- Save notes in localStorage
- Responsive layout for smaller screens
- Different visual styles for each category

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Use the Live Server extension to open the page in your browser.
5. Add, search, and delete notes directly in the app.
